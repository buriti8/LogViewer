Start by using this url/route : http://yourdomain.com/log-viewer

## Dashboard

`log-viewer::dashboard` (`/log-viewer`) shows a chart with the totals per log level across all your logs.

## Logs list

`log-viewer::logs.list` (`/log-viewer/logs`) lists every log file the package can find (see [Configuration](2.Configuration.md) to also list extra, non date-based files such as `worker.log`), with per-level counters and, per row:

  - **View** (magnifying glass): opens the log and its entries.
  - **Download** (down arrow): downloads the raw file.
  - **Clear** (eraser): empties the file's contents without deleting it.
  - **Delete** (trash can): deletes the file. Hidden for the current day's dated log, so the active log is never removed by mistake.

### Delete all listed logs

The **"Delete all listed logs"** button, at the top right of the Logs page, deletes every **dated** log file in one action (confirmation modal included). The current day's active dated log is always kept, same as the single "Delete" action.

Extra/non date-based logs (configured via `pattern.extra`, see [Configuration](2.Configuration.md)) are **not** included by default, even when they're listed on the page — they're usually a single file a long-running process (a queue worker, Horizon, the browser logger...) may still be writing to, so deleting them is kept a deliberate, individual action. If you do want to wipe them too in the same click, the confirmation modal shows a checkbox ("Also delete the N extra logs listed") you can tick before confirming.

## Single log view

`log-viewer::logs.show` (`/log-viewer/logs/{date}`) shows every entry of a log, filterable by level (`log-viewer::logs.filter`) and searchable (`log-viewer::logs.search`).
